## 5.2 提交信息规范

Conventional Commits，中文描述，动词开头，一条提交只做一件事：

```
feat(home): 完成商品列表与分类筛选
feat(detail): 详情页展示价格、成色与卖家信息
fix(search): 修复清空关键词后结果不刷新的问题
docs: 补充智能定价算法说明
```

禁止 `update`、`111`、`fix bug` 这类无信息量的提交信息。

## 5.4 分支策略

- `main`：始终可编译、可运行；
- 功能分支：`feat/pricing`、`feat/image-pipeline` 等，完成后合并回 `main`；
- 伴生模块独立目录 `companion/`，与主 App 同仓库，便于演示「数据打通」。
